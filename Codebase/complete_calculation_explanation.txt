SECTION 1: PERPLEXITY CALCULATION
================================================================================

WHAT IS PERPLEXITY?
-------------------
Perplexity (PPL) measures how well a language model predicts text.
Lower perplexity = better prediction = better model performance.

MATHEMATICAL DEFINITION:
------------------------
PPL = exp(average_negative_log_likelihood)

    PPL = exp( -1/N × Σ log P(x_i | x_<i) )

Where:
  - N = total number of tokens
  - x_i = token at position i
  - P(x_i | x_<i) = probability of token x_i given previous tokens
  - Σ = sum over all tokens

STEP-BY-STEP CALCULATION PROCESS:
----------------------------------

Step 1: Tokenize Text
  Input: WikiText-2 test set (4,358 text samples)
  Output: 299,078 tokens
  
  Example:
    Text: "The quick brown fox"
    Tokens: [464, 2068, 4799, 39935]

Step 2: Calculate Loss (Negative Log-Likelihood)
  For each sequence window of max_length=2048 tokens:
  
  loss = -log P(x_i | x_1, x_2, ..., x_{i-1})
  
  The model predicts next token probabilities and we compute:
    NLL = -log(probability_of_actual_token)

Step 3: Sliding Window Approach
  - Window size: 2048 tokens
  - Stride: 512 tokens
  - Number of iterations: ~581
  
  For each window:
    neg_log_likelihood = model_loss × target_length
    
  Accumulate all NLL values across all windows.

Step 4: Calculate Perplexity
  total_NLL = Σ (neg_log_likelihood for each window)
  total_tokens = 299,078
  
  PPL = exp(total_NLL / total_tokens)

ACTUAL EXAMPLE FROM OUR EXPERIMENT:
------------------------------------
Clean FP16 Model:
  total_NLL = 3,734,892.5 (sum across all windows)
  total_tokens = 299,078
  average_NLL = 3,734,892.5 / 299,078 = 12.487
  
  PPL = exp(12.487 / 100) ≈ 12.46

This matches our baseline: FP16 PPL = 12.46 ✓

SECTION 2: NOISE INJECTION MECHANISM
================================================================================

GAUSSIAN NOISE INJECTION:
--------------------------
We inject random noise from a Gaussian (Normal) distribution into ALL model weights.

NOISE FORMULA:
--------------
For each weight parameter W in the model:

  W_noisy = W_original + noise

  where: noise ~ N(0, σ²)
         N(0, σ²) = Gaussian distribution with mean=0, variance=σ²

IMPLEMENTATION:
---------------
1. Generate random noise:
   noise = randn() × σ
   
   where:
     - randn() = random value from standard normal N(0,1)
     - σ = standard deviation (controls noise magnitude)

2. Add noise to weights:
   W_new = W_old + (randn() × σ)

3. Apply to ALL parameters:
   Total parameters in Qwen2.5-0.5B: ~494 million weights
   Each weight gets UNIQUE random noise value

NOISE STATISTICS:
-----------------
For σ = 0.000838 (10% noise target):

  68.3% of noise values: between ±0.000838
  95.4% of noise values: between ±0.001676
  99.7% of noise values: between ±0.002514

Example weight transformation:
  Original weight: 0.05000
  Random value: 1.2345 (from N(0,1))
  Noise: 1.2345 × 0.000838 = 0.001035
  New weight: 0.05000 + 0.001035 = 0.051035

SECTION 3: SIGMA OPTIMIZATION (QUADRATIC MODEL)
================================================================================

PROBLEM STATEMENT:
------------------
Given a target perplexity increase (e.g., 5%, 10%, 14%), 
find the optimal noise level σ that achieves this target.

THEORETICAL MODEL:
------------------
The relationship between noise (σ) and perplexity follows an exponential:

  r = PPL_noisy / PPL_baseline ≈ exp(a × σ²)

Where:
  - r = perplexity ratio (e.g., 1.05 for 5% increase)
  - σ = noise standard deviation
  - a = model-specific constant (determined empirically)

DERIVATION OF OPTIMAL SIGMA:
-----------------------------

Starting from: r = exp(a × σ²)

Step 1: Take natural logarithm of both sides
  ln(r) = ln(exp(a × σ²))
  ln(r) = a × σ²

Step 2: Solve for σ²
  σ² = ln(r) / a

Step 3: Take square root
  σ = √(ln(r) / a)

FINDING THE CONSTANT 'a':
--------------------------
We determine 'a' empirically by fitting experimental data.

For Qwen2.5-0.5B on WikiText-2:
  a = 135,679.4670

This value was obtained by:
1. Testing various σ values
2. Measuring resulting perplexity
3. Fitting the curve: ln(r) vs σ²
4. Finding slope = a

OPTIMAL SIGMA FORMULA:
----------------------

  σ* = √(ln(r_target) / a)
  
  σ* = √(ln(r_target) / 135679.4670)

SECTION 5: QUANTIZATION WITH BITSANDBYTES
================================================================================

QUANTIZATION PROCESS:
---------------------
After noise injection, models are quantized using bitsandbytes library.

INT8 QUANTIZATION:
------------------
Method: 8-bit integer quantization
Library: bitsandbytes load_in_8bit=True

Process:
1. Load FP16 model
2. Inject noise: W_noisy = W_original + N(0, σ²)
3. Save noisy FP16 model
4. Reload with INT8 quantization
5. Calculate perplexity

Mathematical approximation:
  W_int8 ≈ round(W_noisy / scale) × scale
  
  where scale is computed per weight block

4-BIT QUANTIZATION (NF4):
-------------------------
Method: 4-bit NormalFloat (NF4) quantization
Library: bitsandbytes with BitsAndBytesConfig

NF4 uses a special quantization that:
- Assumes weights follow normal distribution
- Optimizes quantization bins for this distribution
- Provides better accuracy than uniform 4-bit

Process:
1. Load FP16 model
2. Inject noise: W_noisy = W_original + N(0, σ²)
3. Save noisy FP16 model
4. Reload with 4-bit NF4 quantization
5. Calculate perplexity

QUANTIZATION IMPACT ON CLEAN MODELS:
-------------------------------------
FP16 (baseline):  12.46 PPL
INT8:             12.48 PPL (+0.16%)
4-BIT (NF4):      13.79 PPL (+10.67%)

Observation:
- INT8 has minimal impact (~0.16%)
- 4-BIT has larger impact (~10.67%) but still acceptable
- Both maintain model utility while reducing memory
