============================================================
NOISE GENERATION FORMULA
============================================================

For each weight parameter in the model:

STEP 1: Generate Noise
  noise = randn() × σ

  Where:
    - randn() = random sample from standard normal distribution N(0, 1)
    - σ = sigma value (standard deviation)
    - Result: noise ~ N(0, σ²)

STEP 2: Add Noise to Original Weight
  new_weight = original_weight + noise

COMPLETE FORMULA:
  new_weight = original_weight + (randn() × σ)

def inject_weight_noise(model, sigma, record_changes=False):
    for name, param in model.named_parameters():
        if param.requires_grad and param.device.type != 'meta':
            # Generate Gaussian noise with mean=0, std=sigma
            noise = torch.randn_like(param) * sigma
            
            # Add noise to parameters IN-PLACE
            param.data.add_(noise)

Key PyTorch functions:
  - torch.randn_like(param): generates random tensor same shape as param
  - Values drawn from standard normal N(0,1)
  - Multiplying by sigma scales to N(0, σ²)
  - param.data.add_(noise): in-place addition
